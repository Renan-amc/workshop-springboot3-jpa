O projeto consiste em uma aplicação RESTful desenvolvida com Spring Boot 3 que permite realizar operações CRUD (Create, Read, Update, Delete) em um banco de dados relacional. A parte central da aplicação é o mapeamento de entidades JPA, que são usadas para persistir dados no banco. Utilizei o Spring Data JPA para simplificar a comunicação com o banco de dados e o gerenciamento das operações de persistência.
